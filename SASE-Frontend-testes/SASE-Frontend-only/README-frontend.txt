SASE — FRONTEND APENAS (TELAS VISUAIS)

Este pacote contém somente arquivos de frontend. Não foi incluído nem alterado qualquer backend.

Telas adicionadas em frontend/public/pages:
- home.html — Home / Comunicação com o Arduino
- groups.html — Grupos de Horários
- new-group.html — Novo Grupo de Horários
- times.html — Horários
- new-time.html — Novo Horário
- group-times.html — Horários do Grupo Selecionado
- users.html — Usuários

Estilos compartilhados:
- frontend/public/style/admin-visual.css

Os arquivos originais de login, cadastro, assets e estilos foram preservados.

Observações:
- Esta versão é visual: não integra API, banco de dados, autenticação ou Arduino.
- Os dados de exemplo são fictícios.
- Os botões de salvar são ilustrativos e não persistem dados.
- As telas administrativas podem ser abertas diretamente no navegador ou servidas pelo Express estático.
- Os caminhos entre telas são links relativos para facilitar a navegação de demonstração.
